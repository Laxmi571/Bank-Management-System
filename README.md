# Client Corporate – Bank Management System

A desktop-based Bank Management System developed using Java Swing, JDBC, and MySQL. 
The project was developed during a three-week Summer School and later documented 
and evaluated as part of a Software Engineering curriculum project.

##  About the Project

Client Corporate is a beginner-level banking management system designed to 
digitize basic banking operations.

The application provides a graphical interface through which bank employees 
can authenticate themselves, create customer accounts, perform deposits and 
withdrawals, manage account balances, and view transaction records.

The project also served as an application of Software Engineering concepts 
including requirements analysis, system modeling, design, implementation, 
and software testing.

##  Features

- Employee authentication
- Customer account creation
- Account information management
- Deposit and withdrawal operations
- Balance management
- Transaction history
- Transaction record retrieval
- Receipt / statement generation
- Input validation
- MySQL database integration

##  Technologies Used

- **Java** – Core application development
- **Java Swing** – Graphical User Interface
- **JDBC** – Database connectivity
- **MySQL** – Backend database
- **SQL** – Database operations
- **XAMPP** – Local development environment
